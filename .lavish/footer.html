還原對照筆記

  • 唯一斷點為 Tailwind 預設 md（768px），非本 repo 常見的 lg（1024px）自訂斷點 — Footer.tsx 只用了 md: 前綴。
  • 背景色 bg-dark = #282828，文字色 text-text-white = #FFFFFF（見 src/styles/tokens.css）。
  • 「關於」下的兩個連結在原始碼中是 Next.js <Link>（站內導覽），其餘四個社群/相關連結是原生 <a target="_blank">；此還原中站內連結已攔截預設導覽以免離開預覽頁，外部連結維持真實開新分頁行為。
  • 非對稱間距如實還原：pt-[50px] / pb-[50px] / 桌機 px-[70px]、md:min-h-[290px]，以及標題 tracking-[0.085em] 字距 — 這些是原設計本身的數值，非本次調整。
