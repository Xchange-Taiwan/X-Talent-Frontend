Onboarding 精靈還原預覽 — Header ／ 5 步驟精靈 ／ Cover Split ／ Footer

依專案現有原始碼精確還原 src/app/auth/(sign)/onboarding/{page,container,ui}.tsx 目前上線的註冊導引流程：沿用既有 .lavish/home-page.html 的 Header（含 AnnouncementBanner、RWD 導覽列／漢堡選單、已登入下拉選單／行動版 Sheet、分享個人頁面 Dialog）與 Footer 還原成果，以及 .lavish/sign-in-out-page.html 中 (sign)/layout.tsx 的左右分欄（左側頁面內容、右側於 lg （1024px）以上顯示的 cover 圖 + 文案），中間換上真正互動的 5 步驟精靈本體：姓名／頭像、個人資訊、有興趣的職位、想加強的技能、想了解的主題，並在最後一步重現 ui.stories.tsx 的送出動畫與完成畫面。所有欄位驗證訊息取自 src/schemas/onboarding.ts 的實際 zod 訊息，選項資料取自 src/test/fixtures/tagCatalog.ts 的官方 mock fixture（因為真實資料需登入後由 API 取得）。

🎨 設計來源：本專案（X-Talent-Frontend）既有的 Tailwind 設計 token、shadcn 元件樣式，以及既有的 Header／Footer／Cover-split 還原成果，確保與正式環境視覺一致。
⚠️ 還原時發現的既有行為（非本次刻意設計）：Step 1 的 avatarFile（一個瀏覽器 File 物件）會直接放進 ui.stories.tsx 的 JSON.stringify(submittedData) 完成畫面。File 物件序列化成 JSON 會變成空物件 {}，所以上傳頭像後完成畫面的 JSON 只會顯示 "avatarFile": {} 而看不到檔名。此還原忠實重現了這個行為，而非視為 bug 修掉。
